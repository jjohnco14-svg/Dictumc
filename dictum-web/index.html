⚙
Grammar-Constrained AI
The grammar engine exposes a state machine that feeds LLM token masking directly. AI literally cannot generate invalid Dictum — the grammar rejects bad tokens before they're emitted.
🔒
Safe by Default, Unsafe by Choice
All memory is tracked, bounds-checked, and ownership-verified by the validator. Unsafe blocks — raw pointers, extern ABI, transmute — are grammar-gated and validator-scoped.
🎯
6 QEMU Cross-Targets
Write once, run on ARM64, RISC-V, MIPS, PowerPC from the browser. No hardware required. Cross-compile and execute via QEMU user-mode, all from the playground.
