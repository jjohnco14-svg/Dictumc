# Dictum 50 Industry Skills System
## Version: 3.2 Phase 7 — Industry Edition

> **Purpose**: Enable AI systems to act as industry-specialized programmers through the Dictum transpiler ecosystem. Each skill maps Dictum's natural-language syntax to real-world C/C++ systems programming across 25+ industries.

---

## How to Use This System

1. **Start with Skill 1** (Console Application Developer) — learn Dictum fundamentals
2. **Progress through tiers** — each skill builds on previous C/C++ concepts
3. **Pick your industry** — jump to skills relevant to your domain after Tier 2
4. **Ship deliverables** — each skill has concrete projects to build and deploy
5. **Master the backend** — by Skill 50, you understand C/C++ at the language-design level

## Skill JSON Schema

Each skill file contains:
- `name` — Skill title
- `industry` — Target industry/domain
- `tier` — Difficulty level (1-7)
- `description` — What this skill covers
- `deliverables` — Concrete projects to ship
- `dictum_features` — Dictum syntax elements used
- `c_cpp_concepts` — Underlying C/C++ knowledge gained
- `example_snippet` — Working Dictum code example
- `estimated_hours` — Time to mastery
- `prerequisites` — Required prior skills
